## Stops (must change before Phase A)

**S1. Per-entity isolation is vacuous at file granularity (checks 1 and 4, DL-4).** Evidence files are one per source and type per run (`03-lld.md:213`), so "that entity's evidence files" (`03-lld.md:393`, `01-design.md:90`) is every entity's evidence. Every Interpret `inputs:` list is then the same, `CITATION_OUTSIDE_INPUTS` (`02-adrs.md:99-104`) can never fire on a real run, and scenario 3 (`requirements.md:146`) is not met. Smallest fix: Interpret writes a per-entity slice, `interpretations/inputs/<entity>/<source>-<type>.yaml`, same envelope, items filtered to that entity's class and store names, and `inputs:` lists the slices.

**S2. Stage 5 and Stage 4 are not handed what their scripts read (check 4).** LLD §6 hands Validate "the four files, `questions.yaml`, the manifest, last `scorecard.yaml`" (`03-lld.md:395`, same at `01-design.md:92`), but the §4 rules read `sources.yaml` (lines 329 to 331), `evidence/` (314, 315), `run.log` (332), `interpretations/` (317, 318) and the waiver file (305). Fold (`03-lld.md:394`) runs `manifest_tie.py`, which reads `docs/system-manifest.yaml` (`03-lld.md:410`), not in its row. WIRE-1 (`04-test-plan.md:119`) checks stages against §6, so it would fail a correct skill. Fix: add those inputs to the two Handed cells and to HLD §3.2.

**S3. The shared waiver file does not fit the boundary rule (checks 3 and 4).** `check_manifest_agentic.py:33` requires a waiver locus to match `^[a-z0-9][a-z0-9_-]*$` (enforced at line 1153), but the locus is the boundary entity name, which is CapCase (`Invoice` in NEG-21, `UserProfile` in `docs/examples/greenfield/docs/system-manifest.yaml:25`). One such row makes the manifest-agentic check emit `schema_invalid` and, per line 1159, stop every waiver in the file from suppressing. Suppression also needs `tier <= tier_limit` (line 1168); the data-layer validator has no tier input, yet NEG-24 (`04-test-plan.md:39`) tests `tier_limit`. The finding code is `BOUNDARY_NOT_IN_ONTOLOGY` and the waiver code `boundary_not_in_ontology` (`03-lld.md:333`) with no stated normalization. Smallest fix: own file `ci/data-layer/data-layer-waivers.yaml` with the same six-key row shape, locus as the kebab entity id, and `--tier` defaulting to 3 the way `check_manifest_agentic.py:1229` does.

**S4. `lin:` and `fnd:` integers cannot be allocated as specified (check 4).** IDs are integers "never reused" (`03-lld.md:24-25`), each Interpret sub-agent proposes edges and findings in isolation (`03-lld.md:231-234`), so every entity will propose `lin:1`, and Fold is handed `interpretations/` only (`03-lld.md:394`) so it cannot know the previous run's maximum. `ID_DUPLICATE` (NEG-12) would fire on every multi-entity run. Fix: interpretations carry no `lin:` or `fnd:` IDs; Fold assigns them and is additionally handed the previous `lineage.yaml` and `findings.yaml` read-only for continuity, with DL-4's Fold line amended to say so.

NEG-2 (`eta_cache`) passes under either.
