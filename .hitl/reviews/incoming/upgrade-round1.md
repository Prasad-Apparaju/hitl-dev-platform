## Findings

1. **stops** — Claim: `build.sh refuses to build 2.14.0 because shared/team-pulse.md is named by the team-pulse skill but is not in the SHARED_PROSE allowlist.` Evidence: exit 2, `MISSING  shared/team-pulse.md`; `scripts/build.sh:440` lists seven prose files, none of them team-pulse.md; `ai/shared/team-pulse.md` exists in source (80 lines, new in this release); the built `shared/usage-guide.md` also links `team-pulse.md`. Cost if it ships: it cannot ship through build.sh as-is. If the check were bypassed, `/hitl:team-pulse` tells the model its conventions are in a file that is not installed, and the usage-guide row is a dead link. The stale-sweep at build.sh:448-460 deletes any top-level `shared/*.md` not in SHARED_PROSE or SHARED_DOCS, so the file must be added to the allowlist, not just copied.

2. **minor** — Claim: `shipped-validators.sha256 carries a second 2.14.0 hash for skipped_line.py (0025330c…) that matches pre-release commit bff41fd, not any shipped build.` Evidence: source diff v2.13.0..66304b1 adds both `0025330c…` and `e1f70f0f…` for `ci/first-pass/skipped_line.py # 2.14.0`; `git show bff41fd:ci/first-pass/skipped_line.py` hashes to `0025330c…`. Cost: a dead manifest line; migrate_project would silently treat a file from that intermediate commit as "older shipped version", which no product repo should have.

3. **decide** — Claim: `The build only reaches the reachability check with the uncommitted build.sh team-pulse block; release/2.x as committed does not ship pulse.py.` Evidence: `git diff scripts/build.sh` in the scratch copy is the only source of the `shared/tools/team-pulse` copy; the reachability regex would also flag `shared/tools/team-pulse/pulse.py` without it. Cost: a build from a clean checkout of release/2.x fails, or if the block is dropped, the skill's fallback path resolves nowhere. Commit it with the fix for finding 1.

4. **minor** — Claim: `retired-tests.sha256 lists two hashes for test_skipped_line.py, one of which (d54444cf…) is not the 66304b1 file.` Evidence: lines 32-33 of `shared/ci/retired-tests.sha256`. Cost: none for users on 66304b1; extra line only.

Nothing else failed. Checks 4 to 8 and 10 hold on the synced tree and should hold unchanged once finding 1 is fixed, since the fix adds one file and touches nothing they read.
