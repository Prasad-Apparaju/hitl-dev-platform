One more `printf` in that fence, or a changelog sentence that names the exception, closes it. Not a stop: nothing breaks, and the file is harmless if committed.

**Minor**

It reads `../hitl-claude-plugin/skills/dev-verification-review/SKILL.md` from the sibling repo's working tree, which the release build was rewriting at the time (`M hooks/_steps.sh`, `M hooks/welcome.sh` and three more at aa26252). The releasing runbook could say to run the gate before starting the plugin build, or the test could read the plugin's HEAD rather than its working tree.
