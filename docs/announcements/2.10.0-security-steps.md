# HITL 2.10.0: the security steps reach the plan

Released 2026-09-04. Pick it up on an existing project with `/hitl:dev-update`; new installs get it
from `claude plugin install hitl@hitl`.

## What changes for you

**Intake asks one more question.** Does this change touch authentication, authorization, secrets,
personal or payment data? Answer it; HITL will not answer it for you, and not answering is not a
no. A yes puts three steps into the plan that until now could never appear in one: a security
design review after Update Docs, a dependency and CVE audit alongside it, and a penetration test
after Deploy. A changed lockfile brings the CVE audit in on its own.

**When those steps are not in your plan, the record says why.** The sizer writes the reason next
to each one ("conditional (security) not activated: no security sensitive or interfaces changed or
data migration in this change"). The gate checks that reason against the impact record, so a
security step cannot be waved off with a label. If someone marks the pentest not applicable on a
change that touched payment data, the release does not certify.

**Step numbers in the docs match the breadcrumb again.** If you learned that architect code review
is "19a", it is 18a, and has been since impact analysis moved to intake. The step reference and the
summary list in `dev-practices` now carry the runtime's numbers, including the retrospective at 29
and the adversarial substeps at 8a and 16a.

**`/hitl:dev-update` is more careful.** The change-file audit fails closed instead of certifying a
file it could not read. The validator sync installs what is missing, stays quiet on identical
files, shows a diff and asks before touching a file you modified, and leaves files you added alone.
A `.hitl-optout` marker in a validator directory keeps it out of the sync entirely.

## What did not change

The plan is still 31 numbered steps. The new steps are lettered substeps, so nothing renumbered,
and a change that is not security-sensitive sees the same plan it saw before, with three more lines
in the record explaining what was left out and why.
